# Spares frontend

The web app, and the image occlusion editor (SVG-Edit, in the `svgedit` submodule). Run it with `spares_frontend`, or the standalone image occlusion editor with `spares_frontend image-occlusion`.

How the image occlusion editor is used, in the web app and standalone, is documented in the module docs of `spares_frontend` (`spares_frontend/src/main.rs`), and its settings on `ImageOcclusionEditorConfig` in `spares_core`.
